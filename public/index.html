Git Change Review Helper - User Guide
What is this tool?

Git Change Review Helper is a lightweight tool for reviewing changes across multiple commits in a Git repository. It helps you filter commits by regex patterns (e.g., ticket numbers like JIRA-1234) and view consolidated diffs showing only the selected commits' changes.

How to use:
1. Filter Commits
  • Enter a regex pattern in the filter field (e.g., JIRA-1234 or feature/.*login)
  • Matching commits will be highlighted with a blue left border
  • Check "Show only filtered commits" to hide non-matching commits
  • Use "Multi-select" to select multiple commits or disable to select one at a time
2. Select Commits
  • Click on commits to select/deselect them (checkbox or entire row)
  • Selected commits will be highlighted in blue
  • Use "Select All" to select all visible (or filtered) commits
  • The file list updates automatically based on your selection
3. Review Changed Files
  • The file list shows all files modified in selected commits
  • Files are sorted alphabetically for easy navigation
  • Click any file to view its changes
  • Commits with changes to the currently viewed file are highlighted with an orange dot (•)
4. View Diff
  • My Changes Only: Shows only lines added/removed by selected commits (consolidated view)
  • Full File with Marked Changes: Shows the entire current file with your changes highlighted
  • Check "Wrap Lines" to wrap long lines instead of scrolling horizontally
  • Hover over diff headers to see commit details
Example Use Case:

You're working on ticket PROJ-456 with multiple commits over several days. Other developers have also committed to the same files. Use this tool to:

  1. Filter for PROJ-456
  2. See only your ticket's commits
  3. Review all files you changed
  4. For each file, see exactly what YOUR ticket changed, ignoring unrelated modifications by others
Navigation & Shortcuts:
  • Click the ↑ / ↓ buttons to jump between diff hunks
  • Use Shift+Up / Shift+Down keyboard shortcuts to navigate hunks
  • Drag the column edges to resize panels to your preference
  • Click the ‹ button to collapse the commit panel for more diff viewing space
Tips:
  • Continuation lines in commit messages are shown with ⋯
  • The tool consolidates multiple changes to the same line, showing only the net effect
  • Long file names in the file list can be scrolled horizontally
